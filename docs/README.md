## 💡 What This Folder Is For

GitHub serves a community health file from this folder as well as from the root and `.github/`,
but only by its exact name, and nothing here carries one. [`Prompts.md`](Prompts.md) holds the
prompts for working on these defaults with an AI agent: 🔁 Intelligence Sync added it, and from then
on it is this repository's own.
